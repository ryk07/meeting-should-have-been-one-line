One sentence that could have replaced an entire pointless meeting.

## The line

> Nothing has changed since the email, nothing will be decided in this room, and the only action item is this sentence, which just cancelled the meeting.

## How it works

`main.py` (Python 3, stdlib only) writes that single sentence to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The line is
151 characters, one sentence, no context needed: it *is* the meeting,
and it cancels itself.

## Run it

```sh
python3 main.py
```
